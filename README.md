## 🌐 React-Dashboard-Administrativo
Exemplo de Dashboard em React 19.

#### 🎨 Aqui está uma demonstração do Projeto
[https://dash-board-umber-sigma.vercel.app](https://dash-board-umber-sigma.vercel.app)
#### 🔄 Executar a aplicação
- Recuperar as dependencias do projeto node_modules . 
```bash
npm install
```
- Executar o Build do Projeto

```bash
npm run dev
```
